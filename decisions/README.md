# groundwork-steps decisions

One file per decision: `YYYY-MM-DD-what-we-decided.md`. The title is the decision. Each file says what we decided, why, and what we chose against. A decision changes by a new file; the old one says so at the top (`Replaced by` or `Changed in part by`), and nothing else in it is rewritten.

groundwork-steps was cut out of groundwork-bridge on 2026-10-24. How steps came to be a list over one context, and a refusal a named reason, is in groundwork-bridge's decisions: [Steps are a list over one context](https://github.com/p4ulcristian/groundwork-bridge/blob/main/decisions/2026-10-22-steps-are-a-list-over-one-context.md), [A refusal is a named reason, declared on its handler](https://github.com/p4ulcristian/groundwork-bridge/blob/main/decisions/2026-10-23-a-refusal-is-a-named-reason-declared-on-its-handler.md), [An error answer is told from data by one function](https://github.com/p4ulcristian/groundwork-bridge/blob/main/decisions/2026-10-23-an-error-answer-is-told-by-one-function.md).
